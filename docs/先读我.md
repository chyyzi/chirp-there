## 打开项目

1. 先把这个 ZIP **全部解压**。
2. VS Code → 文件 → 打开文件夹 → 选包里的 **AFrame**（打开后应直接看见 `index.html`、`assets`、`js`、`css`、`vendor`）。
3. 右键根目录的 `index.html` → **Open with Live Server**。不要直接双击 HTML，也不要在 ZIP 预览里运行。
4. 等“场景与六只鸟已就绪”，选模式，再点“走进湿地”。首次加载会读取场景、3 个合并动画文件和天空。

如果没有 Live Server 菜单，确认 VS Code 已安装并启用 Live Server，且右键的是 `.html` 文件。

## 两种模式

**观察模式**：路线三只 + 大树终点三只，共六只。可以一直观察、拍照、收集与投喂，没有自动结局。

**故事模式**：从常态天空开始。沿路安静观察夜鹭、红耳鹎、珠颈斑鸠，每只保持在视野中 3 秒，或拍照记录。结局由本轮行为判定；到北侧终点大树附近按 **G**，窗口只显示符合条件的一个结局，点击卡片确认后进入。

| 本轮条件 | 唯一可进入的结局 | 环境 |
| --- | --- | --- |
| 观察 3/3，零惊扰，成功投喂 0～1 次 | 结局 1 · 普通「林间向晚」 | 天空 2，黄昏暖光，终点三只鸟出现 |
| 惊扰至少 2 次，不要求补完观察 | 结局 2 · 坏「无声的林地」 | 天空 3，场景黑白，终点没有鸟 |
| 观察 3/3，零惊扰，成功投喂至少 2 次 | 结局 3 · 梦幻「群鸟之约」 | 天空 4，柔和彩光与微粒，终点三只鸟出现 |
| 观察 3/3，仅惊扰 1 次（补齐未约定情况） | 结局 1 · 普通 | 投喂再多也不会成为梦幻结局 |

**惊扰指鸟真正受惊逃离一次**；仅出现警觉感叹号不算。**投喂指鸟实际吃到一份食物**，地面和手喂都算，放下但没被吃到、伸手后取消不算。同一只鸟多次吃食或返回后再次被惊走，会按实际次数累计。终点固定鸟不参与计数。

梦幻结局要求同一轮满足普通路线条件并投喂两次，不要求先解锁普通结局。梦幻条件满足时只显示结局 3。坏结局优先；一旦惊扰达到两次，本轮不能靠投喂改回普通或梦幻。

结局不会突然自动播放。窗口可以关闭，继续探索；确认前行为仍可改变本轮结局。确认后本轮结局固定，可以留在当前环境拍照、重新开始故事，或进入观察模式。按 H → 故事与结局，可随时查看本轮观察、惊扰、投喂次数及结局收藏。

**集齐三个不同结局后**：进入观察模式 → **H → 故事与结局 → 观察模式·场景**，可选择常态日光、黄昏暖光、黑白林地、梦幻微光。切景不重置位置或物品，终点三只鸟始终保留，观察模式仍为六只鸟。未集齐时按钮为锁定状态。故事模式始终从常态开始。

**切换模式、重开会重置位置、鸟类状态、浆果和本轮记录；照片、永久鸟类图鉴、结局收藏与音量保留。** 按 R 只回入口，不清空本轮进度。刷新开始新一轮，结局收藏与观察场景偏好保存在当前浏览器、当前网站。换浏览器 / 网站地址或清除网站数据不会自动继承；旧版未保存结局收藏，本版从实际完成的新结局开始记录。

## 清屏与相册

**清屏**：按 **U**，或点右上角“清屏”，隐藏游戏 HUD、物品栏、准星、取景框、提示、鸟名、警觉符号及手持道具；再按 **U** 恢复。按一下切换，长按不会重复切换。忘记快捷键时，按 **Esc**，暂停菜单里有“恢复界面 · U”按钮。

清屏不暂停游戏，也不改变相机变焦或物品选择，移动、鸟类互动、警觉与拍照继续正常运行。手册、相册、暂停窗口仍可主动打开。清屏状态仅在本次打开页面期间保留，刷新默认显示界面。

**相册**：按 **P** 打开。

1. 点击照片查看大图，仍可单张保存和删除。
2. 勾选照片下方的“选择”，可多选；点“全选”选中全部，再点“取消全选”清除选择。
3. 点“保存所选（ZIP）”打包勾选的照片；“保存全部（ZIP）”直接打包当前相册全部照片。解压后得到原始 JPG，没有重新压缩画质。若没有自动下载，点击相册里生成的下载按钮。
4. 点“删除所选”，核对张数后点“确认删除”。取消或按 Esc 可撤销这次删除请求；确认删除后无法从相册恢复。已保存到电脑的文件不受影响。

删除照片不会清空鸟类图鉴或结局收藏。照片删除写入浏览器本地相册，刷新后不会重新出现。若删除存储失败，页面会保留照片并提示重试。批量打包 / 删除执行期间暂时禁用相关按钮，避免重复操作。

## 浆果与互动

- 第 1 格固定相机，第 2 格浆果，第 3、4 格空手。每轮初始 6 份，最多携带 24 份，地图生成 24 个可拾取果实，每轮位置不同。
- 地面投喂：选 2，低头对准前方近处的空地左键放置。放下时扣一份，鸟在警觉较低、路线可达时接近。未吃掉的地面食物约 90 秒后清理，同时最多 8 份。
- 手喂：蹲下后按 E，静止 3 秒。转头允许；移动、跳跃、站起、换物品、打开菜单会取消。手里这份只有被鸟实际接受才扣除。
- 路线夜鹭、珠颈斑鸠支持靠近、接受食物、返回。路线红耳鹎保持枝头观察 / 鸣叫。终点三只鸟另外支持定向抛投，均保持原站位。
- 夜鹭没有专门进食动画，暂时用 Friendly 点头回应；珠颈斑鸠使用 Peck。现有三鸟均没有完整 FlyAway，受惊使用现有走 / 跳动作配合渐隐；约 35 秒后且玩家不贴近时返回。
- 游戏浆果是互动道具，玩法不表达真实鸟类的食谱。

## 终点投喂怎么操作

1. 在观察模式，或普通 / 梦幻故事结局完成后，到大树旁找到三只鸟。故事坏结局仍不显示终点鸟；观察模式切黑白场景时三只鸟仍在。
2. 按 **2** 选中浆果，靠近至约 8 个场景单位内；红耳鹎在高处，需要抬头瞄准。
3. 准星对着鸟，底部出现投喂提示后，按 **左键**。不要求蹲下，也不用静止 3 秒；这些条件仍用于路线手喂。
4. 食物会沿短弧线到鸟面前。夜鹭用 Friendly 点头，珠颈斑鸠用 Peck 啄食，红耳鹎复用 Call 的张嘴 / 抬头动作接食。红耳鹎没有独立进食素材，此处为现有动画的复用。
5. 吃完恢复待机，冷却约 2.5 秒后可再次投喂。一次只进行一份终点投喂；连点不会重复扣量。

浆果在抛出时扣 1，吃到时不再扣。若未吃到就被取消或目标隐藏，会退回这份食物（不超过背包上限）；重开模式则按原规则重置为初始 6 份。前方有树干 / 石头挡住抛投路线时，会提示侧移，不扣食物。附近地面的拾取和路线地面投喂仍按原规则执行；直接投喂终点鸟不会让它们走下树枝。

可调参数在 `config.js` → `inventory`：`endingFeedDistance`（距离）、`endingFeedAimAngle`（瞄准容差，弧度）、`endingFeedCooldown`（秒）、`endingFeedFlightSeconds`（抛投时长，秒）。

## 调节音量和参数

最方便：**H → 声音与设置**。鸟鸣总量和夜鹭、珠颈斑鸠、红耳鹎都有单独滑杆。音量立即生效，并保存在当前浏览器。

代码默认值在 `js/config.js` 的 `audio`：

```js
"master": 0.75,
"bird": 0.65,
"heron": 0.8,
"dove": 0.65,
"bulbul": 0.55
```

范围 0～1。鸟声最终还会乘上总音量、鸟鸣总量以及距离衰减。修改代码默认值后，手册点一次**恢复音量设置**，避免旧滑杆值覆盖你的新设置。

其他常改位置：

| 需求 | `js/config.js` 位置 |
| --- | --- |
| 步行 / 跑步速度 | `player.walkSpeed` / `runSpeed` |
| 警觉敏感度 | `birds.dangerDistance`、`sprintAlertPerSecond` 等 |
| 三只路线鸟的位置、大小 | `birds.species` 对应鸟的 x / y / z、modelHeight |
| 终点三只鸟 | `endingPerches` |
| 天空、雾、色调、滤镜 | `environments.normal / dusk / bad / dream` |
| 手喂等待时间 | `inventory.handWaitSeconds` |
| 初始 / 随机浆果数量 | `inventory.initialBerries / spawnCount` |
| 本轮观察时间、终点范围 | `story.observeSeconds / final / finalRadius` |
| 坏结局惊扰次数 / 梦幻成功投喂次数 | `story.badDisturbances / dreamFeedings`（均为 2） |

照片不含取景框、物品栏、鸟名和警觉标记；保留结局环境色调。浏览器清理数据会清空相册，喜欢的照片请下载。
