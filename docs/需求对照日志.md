## 根据实际素材作出的调整

1. **结局现按本轮行为判定，覆盖旧版三选一。** 只呈现唯一符合条件的结局；到大树按 G 后主动确认。惊扰至少 2 次 → 坏；否则观察齐三鸟、零惊扰、成功投喂至少 2 次 → 梦幻；观察齐三鸟、投喂不足 2 次且零惊扰 → 普通。仅惊扰 1 次补为普通结局，仍需观察齐全。具体补充与计数口径见下方修订表。
2. **看见 3 秒或拍照都可以完成本轮观察。** 永久图鉴仍以拍照解锁；两个集合分开，旧照片不会让新故事自动完成。终点固定鸟不会替代路线任务。
3. **红耳鹎不从高枝移动到地面手喂。** 上传动作只有 Gaze / Hop / Call，指定枝面约 Y=6.49；没有上下树飞行动作，直接沿空中走会明显穿帮。本版让它留枝头转头、鸣叫、警觉与跳跃渐隐。后续有完整飞行动作后可再加入下树取食。
4. **现有素材没有 FlyAway。** 夜鹭、鸠使用原地 Walk 配合地面可达路径离开，再渐隐；红耳鹎使用原地 Hop 配合渐隐。没有把静止模型硬拉成完整飞行。归来仅在隐藏时间满足、玩家不贴近时渐显。
5. **夜鹭用 Friendly 表达接受食物。** 它没有 Peck / Forage；本版没有伪造不存在的啄食骨骼动作。鸠使用实际 Peck。手持投喂需要蹲下，避免地面鸟被硬拉到站立玩家手臂高度；不会把它瞬移到手掌上。
6. **保留原始鸟模型外观。** 斑鸠源文件名称写成 Pink-necked green pigeon，但检查模型可见颈侧黑白点等外观，继续按你提供的珠颈斑鸠素材使用；发布文件统一为 dove.glb，没有重新建鸟。
7. **追加 X 潜伏键。** Ctrl 单次切换仍可用；Chrome 的 Ctrl+W 是浏览器保留快捷键，网页不能保证屏蔽。说明里写明先松 Ctrl 再移动，或改用 X。
8. **滤镜采用画布 CSS + 同参数照片导出。** UI 和手册不变成黑白；场景由天空、灯光、雾和滤镜共同构成。梦幻粒子是场景对象，会出现在照片里。
9. **发布包只收运行所需资源。** 场景使用最新文件；重复旧场景、旧测试页面、Blender 源文件不放进运行包。原上传文件仍作为源素材保留。无需在线 CDN、无需 npm 构建，适合原 Live Server / GitHub Pages 流程。

- 场景解析：1,567 个网格，59 个地面网格，415 个阻挡网格；保留实例化合批。入口和路线鸟落点已核对。

- 实际地形下验证了食物靠近、进食、返回；手喂等待 / 取消 / 扣量，警觉 / 逃离 / 回归，三结局终点鸟显示、换模式清理过期回调等。
- 乱序天空加载不会覆盖后选环境；常态能清除黑白滤镜和梦幻粒子。
- Blender 局部实渲检查了两处枝头及终点三鸟，无明显穿主干或埋叶。检查图用于几何站位，不等同网页最终照明。

- 脚步与碰撞沿用最新项目的固定步长和滑动解算，本次没有换物理引擎。鸟类使用局部地面寻路，不会自动越过水体、陡坎或高树枝。

## 2026-10-19 音频修订

实机反馈“部分声音加载失败”后，定位到 `js/audio.js` 的 `loadAssets()`：循环声源错误引用只在 `oneShot()` 局部存在的 `attenuation`，因此背景音乐、风声、水声抛出 ReferenceError。已将这一处连接恢复为 `source.connect(this.channels[channel])`，短音效的独立衰减节点保留。

针对性验证：复现修复前 3 个循环声源启动失败；修复后全部接入各自音量通道并启动；调音量和暂停恢复正常。17 个实际音频文件通过 ffmpeg 解码检查。Web Audio 使用节点模拟验证，尚未 Chrome 实听。
