01 / 出发指南

沿着小路出发

沿小路寻找鸟类。放慢脚步，在合适的距离停下来观察。

Esc关闭窗口 / 释放鼠标
物品与浆果

按 1–4 切换物品。第 1 格是相机，第 2 格是浆果。

收起相机，瞄准近处浆果，左键拾取。选中浆果后，低头瞄准空地，左键放下；未被吃掉的浆果可以收回。

投喂

沿路投喂：选中浆果，蹲下后按 E 伸手，静止等待 3 秒。夜鹭和珠颈斑鸠会在距离合适、前方畅通时靠近。移动、跳跃或切换物品会收回手。

大树下投喂：选中浆果，瞄准鸟，左键送出。等它吃完，可以再次投喂。

观察小贴士

轻按 Ctrl 或 X 后松开，切换潜伏。靠近鸟类时放慢脚步；看到「!」时停下，等它放松。

02 / 镜头笔记

记录林间的相遇

先找一个合适的位置，再举起相机。变焦能帮助你保持距离。

  1. C
    举起相机

    出现取景框；再次按 C 收起。

  2. 滚轮
    调整画面大小

    向上放大、向下缩小。左下角实时显示 1.0×～4.0×。

  3. 左键 / E
    按下快门

    鸟类进入画面且没有被树石挡住时，可留下观察记录。

  4. P
    翻开相册

    点击照片查看、保存或删除。勾选多张照片可批量操作，或点击「全选」。按 U 隐藏界面，便于取景。

保存照片

相册最多收录 60 张照片，保存在当前浏览器。清理网站数据会清空相册，想留存的照片可下载到电脑。

03 / 鸟类清单

林间鸟类

拍下鸟类，点亮图鉴。故事模式的观察与投喂计数来自沿路三只鸟。

观察小记

受惊的鸟会躲开。退远一些，约 35 秒后再来看看。大树下的三只鸟留在栖息点，可以拍照和投喂。

04 / 故事与结局

模式与故事收藏

选择游玩模式，查看本轮进度和已收藏的结局。

切换模式或重开会开始新一轮。照片、图鉴和结局收藏会保留。

故事收藏 0 / 3

结局条件

林间向晚：观察完三只鸟，惊扰少于两次，且未满足梦幻条件。
无声的林地：惊扰达到两次。
群鸟之约：观察完三只鸟，零惊扰，成功投喂至少两次。
鸟受惊离开计一次惊扰，吃到一份浆果计一次投喂。同一只鸟可以重复计数。到大树下按 G 确认结局。

收藏保存在当前浏览器，清除网站数据会重置。
